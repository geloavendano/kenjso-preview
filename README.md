# Kenj So — Interior Design (prototype)

A design prototype for a portfolio site, shared for client review.
Not indexed by search engines.

Static site: open `index.html` through any local web server, e.g.

```
npx serve .
```

Review aids: `?t=6` freezes the hero animation at 6 s; `?fastsketch` draws the
contact-section sketches instantly.
